# Practice2 – Python Control Flow

This repository contains practice examples for Python control flow concepts
based on the W3Schools Python Tutorial.

## Topics Covered
- Boolean Values
- Boolean Comparisons
- Boolean Operators
- If Statements
- If Else
- If Elif Else
- Short Hand If Else
- While Loops
- Break and Continue in Loops
- For Loops

## Source
W3Schools Python Tutorial:
https://www.w3schools.com/python/default.asp

## Structure
- boolean/ → Boolean examples
- if_else/ → Conditional statements
- loops/ → While and for loops
